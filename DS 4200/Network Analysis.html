Part 1 Analysis the Wolfe Primates¶

These data represent 3 months of interactions among a troop of monkeys, observed in the wild by Linda Wolfe as they sported by a river in Ocala, Florida. Joint presence at the river was coded as an interaction and these were summed within all pairs.

There are two files for the data. labels.csv is the file contains information for each monkey, with their genders, ages and their rank in the troop. link_m.csv is the file contains the number of their interaction in the adjacency matrix format.

Note: when load the link_m.csv, set the header to be none.

Load the data and re-arrange the link matrix with the rank. For example, if the original data is:

Then use the following code to get the data visualization for the adjacency matrix.

# Convert matrix to edgelist
edges = []
n = len(link_matrix)
for i in range(n):
    for j in range(n):
        if link_matrix.iloc[i, j] > 0:
            edges.append({
                'source': i,
                'target': j,
                'weight': link_matrix.iloc[i, j]
            })

edgelist_df = pd.DataFrame(edges)

Part 1.3 Make a static network (15 points)¶

Use the edgelist generated from part 1.2, make a bipartite network, such that one side is for male and the other side is for female. The colors of the nodes are decided by the gender. The sizes of the nodes are decided by the age. The width of the edges are decided by the weight.

In [9]:
# Create graph
G = nx.Graph()

# Add nodes with attributes
for idx, row in labels_df.iterrows():
    G.add_node(idx, sex = row['Sex'])

# Add edges from edgelist df
for _, row in edgelist_df.iterrows():
    G.add_edge(int(row['source']), int(row['target']), weight = row['weight'])

# Separate males and females for bipartite layout
male_nodes = [n for n in G.nodes() if labels_df.loc[n, 'Sex'] == 'male']
female_nodes = [n for n in G.nodes() if labels_df.loc[n, 'Sex'] == 'female']
In [10]:
# Create position dictionary for bipartite layout
pos = {}

# Position males on left, females on right
male_y = np.linspace(0, 1, len(male_nodes))
female_y = np.linspace(0, 1, len(female_nodes))

for i, node in enumerate(male_nodes):
    pos[node] = (-1, male_y[i])
    
for i, node in enumerate(female_nodes):
    pos[node] = (1, female_y[i])

# Draw male and female nodes

nx.draw_networkx_nodes(G, pos, nodelist = female_nodes, node_color = 'pink',

# Add node labels
nx.draw_networkx_labels(G, pos)

# Add title and display the visualization
plt.title("Primate Social Network\n(Sky Blue = Male, Pink = Female, Node size = Age)")
plt.axis('off')
plt.show()

Explanation¶

For the original network, version without myself, the structure is more spread out which allows the audience to have a better visualization towards the nodes, and has a distinct clustering pattern. For the second network, version with myself included, the structure is more compact and the nodes for me become like the center of the network. In addition, I believe it creates shorter connections between nodes that have longer distances like a short cut and forms a dense structure.

For both network visualisations, I use spring layouts, which can limit edge crossing, distribute space evenly for each node, and help to show a more natural cluster structure that makes the overall visualization easier to appeal and interprete for the audience. This is effective because it shows the grouping for network clearly, emphasis structure change before and after introducing myself into the network, and more importantly have better readability.

Importance of Data Visualization in Data Analysis¶

Data analysis is an essential tool to help transfer raw data into a visual representation for the audience to understand a topic better. It uses graphs, charts, and matrices to reveal patterns, trends, and anomalies that is hidden. While data visualization helps simplify complex relationships among data, the analyst could better tell their finding to diverse audiences like the decision-maker, general public, etc. Well-designed visualizations can support better decision-making by presenting insights clearly and succinctly. By addressing the gap between data information complexity and people's cognition, visualization allows analysts to make stronger conclusions and share their insights compellingly and engagingly.

In this case, I am targeting a general audience with little or no previous knowledge of the topic, and I am using simple and clear content to ensure that everyone can understand it.
